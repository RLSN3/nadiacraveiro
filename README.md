# Nádia Craveiro | Estomaterapia e Podiatria Clínica

Site oficial de Nádia Craveiro, enfermeira especialista em estomaterapia com habilitação em podiatria clínica (Coren-CE 668024).

Endereço: https://www.nadiacraveiro.rlsn.com.br

## Publicação (GitHub Pages)
1. Envie todos os arquivos desta pasta para a raiz do repositório.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. O arquivo `CNAME` já aponta para `www.nadiacraveiro.rlsn.com.br`. No DNS do domínio, crie um registro **CNAME** de `nadiacraveiro` para `SEU-USUARIO.github.io`.
4. Depois que o domínio validar, marque **Enforce HTTPS**.

## Estrutura
- `index.html`: página principal.
- `conteudos/<assunto>/index.html`: artigos educativos (URLs amigáveis).
- `assets/fonts/`: fontes usadas pelos artigos.
- `sitemap.xml` e `robots.txt`: indexação no Google.
- `cookies.js`: aviso de privacidade e Google Analytics (só com consentimento).
- `politica-de-privacidade.html`: política de privacidade.
- `googlebb8bce7fafd8c011.html`: verificação do Google Search Console.
